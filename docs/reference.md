# 能力展示

该 skill 面向一页式技术洞察，不是多页演示模板。它把来源材料压缩为可编辑 PowerPoint，并保留可验证事实与结论之间的边界。

| 输入类型 | 推荐故事线 | 主要交付 |
| --- | --- | --- |
| 技术论文 | 问题 → 方法 → 效果 | 一页研究洞察、原图或可编辑机制图、量化效果与证据边界 |
| 技术进展或结果 | 事件概览 → 关键动作 → 结果 | 一页事件快报、关键数据与决策启示 |
| breaking technical news | 事实概览 → 技术影响 → 下一步关注 | 一页快报与清晰标注的已知/未知边界 |

## 典型页面结构

```text
一句话红色主标题
浅灰事件概览条
┌─────────────── 正文证据区 ───────────────┐
│ 问题 / 背景  │ 方法 / 动作 │ 效果 / 数据 │
└──────────────────────────────────────────┘
红色“洞察启示”标签 + 灰色结论与建议区
```

## 能力点

- 用一句话标题直接总结事件，而不是只写主题名。
- 优先复用来源中的原始图表，并给出短图注或来源标识。
- 对技术论文稳定采用“问题 → 方法 → 效果”的证据链。
- 使用确定的企业红灰色值、微软雅黑和 Arial，保持可编辑和可汇报。
- 用脚本检查 PPTX 结构、严格单页和无动画时序节点。

## 示例来源与公开状态

初始版本来自用户提供的 `create-single-page-tech-report` 规则集。当前仓库不捆绑主题性示例 PPTX，以免把特定论文或未授权材料作为公开样例。首次使用时应将任务产物写入 `.tmp/`，只有经用户确认可公开的案例才适合补充到本页。

仓库中的 [SKILL.md](https://github.com/Real-UtopiaNo/create-single-page-tech-report/blob/main/SKILL.md) 是规则来源，[自动校验脚本](https://github.com/Real-UtopiaNo/create-single-page-tech-report/blob/main/scripts/validate_single_page_report.py) 是机器检查入口。文档状态为 `bootstrap`，不宣称已有公开案例通过视觉验收。

## 能力边界

- 不根据缺失信息补造数据、日期、主体或对比结论。
- 自动校验不判断标题是否准确，也不判断图表是否真正支撑结论。
- 不保证在没有 PowerPoint 生成能力的 Agent Runtime 中完成 `.pptx` 创建。
- 不把渲染 PNG 当作可编辑 PowerPoint 的替代品。
